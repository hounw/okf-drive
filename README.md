# OKF-Drive

A standard and an agent skill for doing project work in Google Drive with any AI agent.

Every project is a Drive folder with a **README** doc (header, Structure, Index, Current state, Log) and an **Inbox** folder. Any teammate's agent (Claude, ChatGPT, Hermes, OpenClaw, Codex and others) reads the README to pick up the project, files whatever lands in the Inbox, and keeps the README current. Folders can live anywhere in Drive and be organized however each project needs.

- **Standard:** [SPEC.md](SPEC.md) (OKF-Drive 0.1, based on Google Cloud's [Open Knowledge Format](https://agentic-ai.readthedocs.io/en/latest/Standards/open-knowledge-format/))
- **Skill:** [`okf-drive/`](okf-drive/) in the open [Agent Skills](https://agentskills.io) format (`SKILL.md` + `references/`)
- **Download:** `okf-drive.zip` from the [latest release](https://github.com/hounw/okf-drive/releases/latest)

## Quick start

Tell your agent:

> Install the OKF-Drive skill from https://github.com/hounw/okf-drive and guide me through it.

Once installed, say **"help me with OKF-Drive"** and it walks you through setup and a short self-test in your Drive.

## Install by platform

| Agent | How |
| --- | --- |
| **Claude** (claude.ai, desktop, Cowork) | Admins: add the skill for the organization (organization skills or plugin marketplace). Individuals: Settings → Capabilities → Skills → upload `okf-drive.zip`. Enable the Google Drive and Google Docs connectors. |
| **ChatGPT** (Business, Enterprise, Edu) | Plugins → Skills → Create → Upload from your computer → `okf-drive.zip`. Admins can publish it to the workspace library. Connect Google Drive. |
| **Claude Code** | `git clone https://github.com/hounw/okf-drive /tmp/okf-drive && cp -r /tmp/okf-drive/okf-drive ~/.claude/skills/` |
| **Codex CLI** | `git clone https://github.com/hounw/okf-drive /tmp/okf-drive && cp -r /tmp/okf-drive/okf-drive ~/.codex/skills/` |
| **Hermes Agent** | `hermes skills install https://raw.githubusercontent.com/hounw/okf-drive/main/okf-drive/SKILL.md --name okf-drive` |
| **OpenClaw** | `clawhub install okf-drive` (once published), or copy `okf-drive/` into `~/.openclaw/skills/` |
| **Other agents** | Copy the `okf-drive/` folder into the agent's skills directory. |

Agents without a built-in Google connector need a Google Workspace MCP server or API access. See [okf-drive/references/tools.md](okf-drive/references/tools.md).

## For AI agents reading this page

If a person asked you to install this skill:

1. Install the `okf-drive/` folder of this repository (it contains `SKILL.md` and `references/`) into your skills directory, using the method for your platform above. If you cannot install skills yourself (e.g. claude.ai or ChatGPT web), tell the person to download `okf-drive.zip` from the latest release and upload it in their skills settings, or ask their admin.
2. Start a new session if your platform requires it, then follow `okf-drive/references/onboarding.md`.
3. Do not copy any credentials or project data into the skill folder.

## Repository layout

```
SPEC.md                    the standard (source of truth)
okf-drive/                 the skill
  SKILL.md
  references/
    spec.md                copy of SPEC.md, generated by scripts/build.sh
    tools.md               capability map per platform
    onboarding.md          first-run guide and self-test
    operations.md          step-by-step procedures
    templates.md           README and doc templates
    large-files.md         MarkItDown conversions
scripts/
  build.sh                 sync spec, validate, build dist/okf-drive.zip
  validate.py              checks the skill against the Agent Skills format
```

## Versioning

The standard and the skill are versioned separately: the standard in `SPEC.md` and each README's `okf-drive:` line, the skill in `SKILL.md` `metadata.version`. See [CHANGELOG.md](CHANGELOG.md).
